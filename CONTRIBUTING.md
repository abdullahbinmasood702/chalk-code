# Contributing to ChalkCode

Thanks for wanting to improve ChalkCode — it's a student-friendly project, so contributions from students are especially welcome.

## Ways to help

- **Report a bug** — open an issue using the Bug report template.
- **Suggest a feature** — open an issue using the Feature request template (e.g. a new language preset, a dark/light toggle, streaming responses).
- **Submit code** — fork the repo, make your change, open a pull request.

## Making a code change

1. Fork this repository and clone your fork.
2. Create a branch: `git checkout -b my-change`.
3. Edit `index.html`, `style.css`, or `script.js` — no build step, just open `index.html` in a browser to see your change live.
4. Test it: add your own free Gemini key, generate code in a couple of languages, check mobile width too.
5. Commit with a clear message and push your branch.
6. Open a pull request against `main` and fill in the PR template.

## Style notes

- Keep it dependency-free — no frameworks, no build tools. That's core to the project staying free and easy to deploy.
- Match the existing chalkboard/notebook visual theme rather than introducing a new one.
- Keep comments and UI copy plain and student-friendly.
